# 🎯 Color Target Shooter

A simple and interactive 2D mouse-clicking game built using Python and Pygame for the **Computer Graphics and Design Lab** project.

## 📝 Game Overview
**Color Target Shooter** is a 2D reflex-based arcade game. Colored geometric targets appear randomly on the screen, and the player must click on them using the mouse to score points before time runs out.

## 🛠️ Technologies & Graphics Concepts Used
* **Language:** Python 3.x
* **Library:** Pygame
* **Computer Graphics Concepts:** 2D Coordinate System, Circle Drawing Algorithms, Color Filling, and Point-in-Circle Collision Detection.
